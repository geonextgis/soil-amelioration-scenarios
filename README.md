# Soil Amelioration Scenarios

Crop-model (SIMPLACE / LINTUL5) simulation framework for evaluating soil
amelioration scenarios across baseline, historical, and future climate in Germany.

**Crops** (calibrated in two stages: phenology, then LAI + yield jointly):
winter wheat, winter rapeseed, spring barley, potato, maize.

**Experiment matrix:** 17 climate scenarios × 5 soil scenarios = **85 experiments**
per crop.

| Type       | Period    | Climate                   | Scenarios | Management (`vIDPL`)           |
| ---------- | --------- | ------------------------- | --------- | ------------------------------ |
| Baseline   | 1979–2024 | DWD observations          | 1         | dynamic, per observed year     |
| Historical | 1951–2014 | HYRAS OBS + 5 GCMs        | 6         | median IDPL per district (NUTS) |
| Future     | 2015–2100 | 5 GCMs × {SSP126, SSP370} | 10        | median IDPL per district (NUTS) |

## Layout

```
data/raw/            soil scenarios, PointID -> grid mapping, site geometries
notebooks/           00_exploration .. 04_evaluation (input prep + evaluation)
optimization/        agentic calibration in two stages (phenology, then joint
                     LAI + yield): local Ollama agents + Claude Code agents
orchestration/       experiments.yaml + generate.py (the 85-experiment matrix)
simplace/<crop>/     the SIMPLACE model, inputs, and cluster runner
```

## Quickstart

```bash
# List the 17 climate sources
python orchestration/generate.py --list-climates

# Preview without writing anything
python orchestration/generate.py --crop maize --climate DWD --soil S1 --dry-run

# Generate an isolated run dir (simplace/<crop>/runs/<climate>__<soil>/)
python orchestration/generate.py --crop maize --climate GFDL-ESM4_ssp370 --soil S2

# Submit to SLURM
python simplace/maize/simplace_runner_cluster.py \
    simplace/maize/runs/GFDL-ESM4_ssp370__S2/config.yaml
```

`--crop`, `--climate` and `--soil` each accept a single value, a comma-separated
list, or `all`.

## Paths

Nothing hard-codes the repository location: the root is derived from each file's
own path, so the checkout can be moved or cloned anywhere. Both config files set
`repo_root: auto`; set `SOIL_SCENARIOS_ROOT` to override.

Paths *outside* the repo (shared cluster stores) stay absolute but are
env-overridable: `EXTERNAL_DATA_DIR`, `DWD_PHENOLOGY_DATA`, `DWD_CLIMATE_DIR`.

## Prerequisites

A fresh clone does **not** contain the derived model inputs — they are gitignored
(~120 MB) and regenerated by `notebooks/01_preprocessing/`:

```
simplace/<crop>/project/project_<crop>.csv    <- 04_prepare_simplace_project_file
simplace/<crop>/data_observed/                <- 01_data_preparation, 02_..., 03_...
```

Run those notebooks before simulating. SIMPLACE itself runs from a Singularity
image on the cluster (see `slurm.singularity_image` in `orchestration/experiments.yaml`).
